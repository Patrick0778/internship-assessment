# Sunbird AI GenApp

A minimal, editorial-style Generative AI web application that lets users provide **text** or an **audio file**, summarises the content, translates the summary into a chosen Ugandan local language, and synthesises the translated summary into natural-sounding speech. All AI capabilities are powered entirely by the [Sunbird AI API](https://api.sunbird.ai) — no external model providers are used.

---

## Architecture Overview

The app follows a linear pipeline orchestrated in `backend/pipeline.py`:

```
┌─────────────┐     ┌──────────────┐     ┌────────────┐     ┌────────────┐     ┌──────────────┐
│   Input     │────▶│ Transcribe   │────▶│ Summarise  │────▶│ Translate  │────▶│ Synthesise   │
│ (text/audio)│     │ (STT if audio)│     │(Sunflower) │     │(Sunflower) │     │ speech (TTS) │
└─────────────┘     └──────────────┘     └────────────┘     └────────────┘     └──────────────┘
                                                                                        │
                                                                                        ▼
                                                                              ┌──────────────────┐
                                                                              │ Display results  │
                                                                              │ + playable audio │
                                                                              └──────────────────┘
```

| Step | Endpoint | Description |
|------|----------|-------------|
| **1. Input** | UI | Accept typed text OR uploaded audio (MP3, WAV, OGG, M4A, AAC) |
| **2. STT** | `POST /tasks/stt` | Convert audio to text (supports English, Luganda, Runyankole, etc.) |
| **3. Summarise** | `POST /tasks/sunflower_simple` | Condense text to 2–3 sentences using the Sunflower LLM |
| **4. Translate** | `POST /tasks/sunflower_simple` | Translate the summary into Luganda, Runyankole, Ateso, Lugbara, or Acholi |
| **5. TTS** | `POST /tasks/tts` | Generate spoken audio of the translated summary |
| **6. Output** | UI | Shows original text, transcript, summary, translated summary, and an audio player |

**Tech stack**
- **Frontend:** [Gradio](https://www.gradio.app/) (Python)
- **Backend:** Python (`backend/`) — thin API wrapper + pipeline orchestrator
- **Styling:** Custom CSS matching the ElevenLabs-inspired `DESIGN.md` system — off-white canvas, editorial serif display type, atmospheric pastel gradient orbs, pill-shaped CTAs, and soft hairline borders.

## Local Setup

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/internship-assessment.git
cd internship-assessment
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv

# Linux / macOS
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` and replace the placeholder with your actual Sunbird AI API token:

```bash
# .env
SUNBIRD_API_TOKEN= YOUR_SUNBIRD_AI_API_TOKEN
```

> **Get a token:** Sign up at [Sunbird AI API Portal](https://api.sunbird.ai/).
> **Never commit your token to git.**

### 5. Run the app locally

```bash
python app.py
```

## Usage

### Text input workflow

1. **Choose input type:** Select **text** from the *Input type* radio buttons.
2. **Enter text:** Paste or type your content into the text area.
3. **Pick a language:** Choose your target language from the dropdown (e.g. *Luganda*).
4. **Click Process:** The pipeline runs and displays:
   - **Original text** — what you typed.
   - **Summary** — a concise 2–3 sentence summary generated by the Sunflower LLM.
   - **Translated summary** — the summary translated into your chosen language.
   - **Synthesised speech** — an audio player you can listen to immediately.

### Audio input workflow

1. **Choose input type:** Select **audio** from the *Input type* radio buttons.
2. **Upload audio:** Drag and drop or click to upload an audio file (MP3, WAV, OGG, M4A, AAC). Files **longer than 5 minutes** will be rejected with a clear error message.
3. **Pick a language:** Choose your target language.
4. **Click Process:** The pipeline runs and displays:
   - **Original text / Transcript** — the transcribed text from your audio.
   - **Transcript (audio only)** — a duplicate of the transcript for clarity.
   - **Summary** — the AI-generated summary.
   - **Translated summary** — the translated summary.
   - **Synthesised speech** — playable audio in the target language.

### Deployed link

### How to redeploy (if needed)

1. Create a free account at [huggingface.co/join](https://huggingface.co/join).
2. Create a new Space → choose **Gradio** SDK and **Public** visibility.
3. Add your Sunbird API token as a Space secret:
   `Space settings → Variables and secrets → New secret → Name: SUNBIRD_API_TOKEN`
4. Push your code to the Space's git repository:

```bash
# From your project root
huggingface-cli login                       # one-time auth
git remote add space https://huggingface.co/spaces/<your-username>/sunbird-ai-genapp
git push space main
```

Hugging Face will build and deploy automatically.

## Known Limitations

1. **TTS endpoint latency:** The Sunbird AI Text-to-Speech (`/tasks/tts`) endpoint occasionally experiences **server-side timeouts** (> 3 minutes). When this happens, the app surfaces the error to the user rather than hanging silently.
2. **5-minute audio cap:** Audio uploads longer than 5 minutes are rejected client-side. The Sunbird API itself supports up to 10 minutes, but the app enforces a 5-minute limit per the brief.
3. **Language coverage:** Translation and TTS support five Ugandan languages (Luganda, Runyankole, Ateso, Lugbara, Acholi). English input is supported via both text and STT, but English is not a translation target.
4. **No conversation history:** Each request is stateless; the app does not remember previous interactions.
5. **STT language detection:** The STT endpoint auto-detects language in the audio. The transcript may occasionally be returned in a language different from the user's expectation if the audio quality is poor.
